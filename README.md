-PlayerCard: The Digital Profile for Gamers

PlayerCard is a full-stack MERN application that allows gamers to create a shareable digital profile. Users can track their current games, platforms, and ranks in one centralized, responsive interface.

-Features

*   User Accounts: Secure Register, Login, and Logout functionality using JWT.
*   Comprehensive CRUD: Users can Create, Read, and Delete games from their personal dashboard.
*   Public Profiles: Shareable URLs (`/profile/:username`) that allow anyone to view a player's card.
*   Responsive Design: Fully optimized for both mobile and desktop viewing.
*   Persistent Data: All user data and game lists are stored securely in MongoDB.

-Tech Stack

*   Frontend: React, Axios, React Router
*   Backend: Node.js, Express
*   Database: MongoDB via Mongoose
*   Authentication: JSON Web Tokens (JWT) & bcrypt.js
